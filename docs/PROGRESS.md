# PROGRESS.md — ความคืบหน้าเฟิร์มแวร์

อัปเดตล่าสุด: 20 พ.ย. 2026 · เวอร์ชัน 0.1.0

## ทำเสร็จแล้ว (ยังไม่ได้ทดสอบกับฮาร์ดแวร์จริง)

- โครงโปรเจกต์ PlatformIO: env `devkit` (ใช้งานจริง), `sensor_test` (ทดสอบเซนเซอร์อย่างเดียว), `native` (unit test บนคอม)
- อ่าน JSN-SR04T: ยิง 7 ครั้งต่อรอบ ทิ้งค่าที่ไม่มีเสียงสะท้อน/ใกล้กว่า 25 cm/ไกลเกิน แล้วเอาค่ากลาง
- คำนวณระดับน้ำ (cm และ %) — สูตรแยกไว้ใน `lib/waterlevel_core` มี unit test 9 กรณี ผ่านทั้งหมด
- ต่อ Wi-Fi + ThingsBoard (MQTT) แบบไม่ค้าง หลุดแล้วต่อใหม่เอง
- ส่ง telemetry ทุก 10 วินาที + attributes ของเครื่องครั้งเดียวหลังต่อได้
- ไฟสถานะ LED บนบอร์ด

## สิ่งที่ควรรู้

- หน้าเว็บขึ้น **Offline** ถ้าบอร์ดไม่ส่งข้อมูลนานเกินช่วงที่ตั้งไว้ใน ThingsBoard — ถ้าไฟสถานะกะพริบ ให้ดู Serial Monitor
- เกณฑ์แจ้งเตือน (DANGER ฯลฯ) อยู่ที่หน้าเว็บ ไม่ใช่ในเฟิร์มแวร์
