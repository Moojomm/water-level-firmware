# การต่อขา (Wiring)

อ้างอิงจาก PCB ใน EasyEDA (Sheet_1 / PCB_rrrrr) — ค่าขาในโค้ดอยู่ที่ [`src/pins.h`](../src/pins.h)

## หัวต่อบน PCB

| หัวต่อ | หน้าที่ | ขา |
|---|---|---|
| J1 | เทอร์มินัลไฟเข้า 5V | 1 = +5V, 2 = GND |
| J2 | หัวต่อเซนเซอร์ (Header ตัวผู้ 1×4) | 1 = VCC, 2 = TRIG, 3 = ECHO, 4 = GND |
| J3 | Female Header แถวซ้ายของ ESP32 | EN … VIN |
| J4 | Female Header แถวขวาของ ESP32 (ไม่ได้ต่อสาย ใช้ยึดบอร์ด) | D23 … 3V3 |
| R1 / R2 | ตัวต้านทานแบ่งแรงดัน ECHO | 1 kΩ / 2 kΩ |

## สายแต่ละเส้น

| Net | จาก | ไป |
|---|---|---|
| +5V | J1-1 | J2-1 (VCC), ESP32 VIN (J3-15) |
| GND | J1-2 | J2-4, R2, ESP32 GND (J3-14) |
| TRIG | J2-2 | ESP32 **D26** (J3-9) — ต่อตรง |
| ECHO_5V | J2-3 | R1 |
| ECHO_3V3 | จุดต่อ R1–R2 | ESP32 **D27** (J3-10) |

ECHO ของ JSN-SR04T ส่งออก **5V** แต่ขา ESP32 รับได้ไม่เกิน 3.3V จึงแบ่งแรงดัน: 5V × 2k / (1k + 2k) ≈ **3.3V**

## สายเซนเซอร์

กล่องควบคุมของ JSN-SR04T มีขาเรียง `5V, Trig, Echo, GND` ตรงกับ J2 ใช้สายจัมเปอร์เมีย-เมีย 4 เส้นต่อตรง 1:1

## ทดสอบวงจรแบ่งแรงดัน (ทำก่อนเสียบ ESP32)

1. จ่ายไฟ 5V เข้า J1 (ยังไม่เสียบ ESP32)
2. ใช้สายจัมเปอร์ต่อขา VCC กับ ECHO บน J2 ชั่วคราว
3. วัดแรงดันระหว่างรู D27 (J3-10) กับ GND

| ค่าที่วัดได้ | แปลว่า |
|---|---|
| ~3.3V | ถูกต้อง |
| ~1.7V | ใส่ R1/R2 สลับกัน (R1 ต้องเป็น 1k ฝั่งเซนเซอร์) |
| ~5V | R2 ไม่ได้บัดกรีหรือบัดกรีไม่ติด — **ห้ามเสียบ ESP32** |

## ทิศการเสียบ ESP32

บน PCB มีคำว่า **ANTENNA** ด้านบน และ **USB ↓** ด้านล่าง — เสียบให้ช่อง USB หันลงตามลูกศร ขา EN อยู่บนสุดของแถวซ้าย
